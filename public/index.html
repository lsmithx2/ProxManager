Connect a Proxmox host

  1. Select Add server to generate a unique server token. It is shown once.
  2. Run this command as root in the Proxmox host shell:
  3. Paste the server token into the installer's hidden prompt. The installer configures and starts the agent automatically.
  4. Return to Servers. The first heartbeat should appear within a minute.

New installations monitor only. To allow maintenance, edit /etc/proxmanager/config.json, add approved actions to allowed_actions, and restart proxmanager.

Allowed actions: refresh-updates, install-updates, reboot. The agent connects over HTTPS every 20 seconds and opens no listening port.

Upgrades use the host's configured repositories. Check backups, cluster health and running workloads before requesting maintenance.
